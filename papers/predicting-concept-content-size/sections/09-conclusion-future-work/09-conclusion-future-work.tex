\textbf{Future work:}
\begin{itemize}
    \item Run the blind-comparison study (\S\ref{sec:evaluation}) and report
          results; this is the paper's current critical path item.
    \item Extend the pilot to additional books/domains beyond Algebra I to test
          generalization.
    \item Re-run the Claude-vs-Gemini/Antigravity comparison under controlled
          conditions (same learning graph, same chapter, both models, content
          preserved this time) to test the ``implicit CIS-like weighting'' claim
          directly rather than anecdotally.
    \item Extend CIS-weighted allocation from word count alone to the full
          multi-dimensional elaboration budget (worked examples, diagrams,
          MicroSims, contrasting cases) proposed in \S\ref{sec:problem-statement}.
    \item Explore combining CIS with other centrality measures (e.g. betweenness,
          for concepts that bridge otherwise-separate parts of the curriculum)
          as a richer importance signal.
    \item Formal user study with instructors/students rating learning outcomes,
          not just subjective content-quality ratings.
\end{itemize}
