Vygotsky's Zone of Proximal Development (ZPD) has been an abstraction taught in the learning sciences for almost 100 years.  But could you explain it to a student?  Using my MicroSim generator skill, Claude and I have created three fun ways for you to visualize the ZPD and interact with it so you can easily remember it.

🟢 Green = mastered (don't waste time here the students already know it)
🟠 Amber = the ZPD (guidance actually works here)
🔴 Red = frustration zone (prerequisites missing — don't try to explain these concepts yet)

So how do we simulate learning?  Just click any amber concept, and watch it instantly flip green while previously red concepts light up amber in real time. The ZPD isn't a fixed spot — it's a continually moving frontier that changes every time you learn something, and now you can watch it happen instead of just being told.

Comes with Concentric, Left-to-Right, and Top-to-Bottom layouts, because seeing different
perspectives help you focus on the structure, not just the placement of concepts in a view.

Built for our open-source "Learning Graphs" textbook.
